A make.fun entry for the **The Robot Pickup Line Championship** competition
(`u-jolly-fox-32-the-robot-pickup-line-championship-3c177b1b`).

`main.ts` (Node 22, stdlib only) writes exactly one pickup line to
`/output/entry.txt` (`$MAKEFUN_OUTPUT_DIR/entry.txt` when set):

> I calibrated my sensors on a thousand faces — then you walked in, and every reading just said 'again'.

102 characters, 104 bytes, one sentence. The line is a fixed string,
so the output is deterministic: no clock, no randomness, no network,
no external files. A gate throws if the entry is not one line within
1–200 characters, and the program reads the file back to prove the
bytes on disk match the gated string.

The pick: a calibration run over a thousand faces flips in the last
word — the sensors do not report a number, they ask to see her again.
The thousand faces are what make "again" land; the narrator is the
self-owning victim (his careful calibration is useless the moment she
walks in); the line asks for nothing, not even her name, so she is
flattered and free to laugh it off.
